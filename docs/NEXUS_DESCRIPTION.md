# Dialogue Enter Confirm

## Русский

Подсветите вариант диалога стрелками ↑↓ и нажмите Enter, чтобы подтвердить его. Мод вызывает штатную команду BG3, не меняет содержание диалогов и сохраняет выбор мышью и цифровыми клавишами.

**Требования:** Baldur's Gate 3 Patch 8, Baldur's Gate 3 Script Extender v32+.

**Проверенная цель:** Windows, клавиатура, одиночная игра. Мультиплеер, Steam Deck и контроллеры не заявляются до отдельной проверки.

## English

Highlight a dialogue answer with ↑/↓ and press Enter to confirm it. The mod calls BG3's native dialogue command and keeps mouse and number-key selection unchanged.

**Requirements:** Baldur's Gate 3 Patch 8 and Baldur's Gate 3 Script Extender v32+.

**Verified target:** Windows keyboard single-player. Multiplayer, Steam Deck, and controller support are not claimed until tested.

## Installation

Install the included `.pak` with BG3 Mod Manager or Vortex. Script Extender is a separate requirement. See `INSTALL.md` in the download archive.
