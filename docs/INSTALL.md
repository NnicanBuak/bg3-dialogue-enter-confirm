# Dialogue Enter Confirm — установка

## Требования

- Baldur's Gate 3 Patch 8 на Windows;
- Baldur's Gate 3 Script Extender v32 или новее;
- BG3 Mod Manager или Vortex (необязательно, но рекомендуется).

## Установка вручную

1. Установите Script Extender отдельно по его официальной инструкции.
2. Распакуйте `DialogueEnterConfirm_v1.0.0.pak` в:
   `%LocalAppData%\Larian Studios\Baldur's Gate 3\Mods`
3. Запустите BG3 Mod Manager или Vortex и активируйте **Dialogue Enter Confirm**.
4. Запустите игру и откройте диалог.

## Установка через менеджер модов

Импортируйте `.pak` из архива в BG3 Mod Manager или Vortex, активируйте мод и сохраните порядок загрузки. Дополнительных модов для этой функции не требуется.

## Использование

В диалоге нажмите ↑/↓, чтобы выбрать ответ, затем Enter или Enter на цифровом блоке. Цифровые клавиши и выбор мышью остаются доступными.

## Обновление

Закройте игру, замените старый `.pak` новым и снова активируйте мод в менеджере. Сохранения не изменяются.

## Удаление

Удалите мод в менеджере или удалите файл `DialogueEnterConfirm_v1.0.0.pak` из папки `Mods`. Мод не добавляет серверные данные и не требует очистки сохранений.

## Ограничения первого релиза

Проверенная цель — одиночная игра с клавиатурой на Windows. Мультиплеер, Steam Deck и контроллеры пока не заявляются. Если Enter не работает, сначала проверьте, что установлен BG3SE v32+, мод активен, а в диалоге действительно видны варианты ответа.
