# Dialogue Enter Confirm v__VERSION__

## Что нового

- Добавлено подтверждение выделенного ответа клавишей Enter.
- Используется штатная команда `SelectorEnterCommand` из UI диалога BG3.
- Удержание Enter не повторяет выбор.
- Чат и видимые перекрывающие окна не получают подтверждение диалога.

## Требования

- Baldur's Gate 3 Patch 8;
- Baldur's Gate 3 Script Extender v32+;
- Windows PC.

## Проверка

Автоматические проверки структуры, Lua, JSON, XML и упаковки проходят. Игровая проверка требует ручного запуска BG3 и должна быть выполнена до объявления стабильного релиза. Мультиплеер не проверен.

## Файлы

- `DialogueEnterConfirm_v__VERSION__.pak` — мод;
- `DialogueEnterConfirm_v__VERSION___Install.zip` — мод и краткая инструкция;
- `DialogueEnterConfirm_v__VERSION___Source.zip` — исходные файлы;
- `SHA256SUMS.txt` — контрольные суммы.
