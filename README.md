# Dialogue Enter Confirm для Baldur's Gate 3

Простой и удобный мод для Baldur's Gate 3, который позволяет подтверждать выбор диалогов клавишей Enter.

![Демонстрация мода](docs/demo.gif)

## 🎮 Описание

Теперь вы можете подтверждать выбранную опцию диалога клавишей **Enter** (или кнопкой **A** на контроллере) вместо нажатия цифр. Навигация стрелками ↑↓ уже встроена в игру.

### ✨ Основные функции

- **Enter** - подтверждение выбранной опции диалога
- **↑↓** - навигация между вариантами ответов (встроенная функция игры)
- **Кнопка A** - подтверждение на контроллере
- Совместимость с клавиатурой и контроллером
- Не влияет на геймплей - только улучшает удобство управления

### 🎯 Для кого этот мод?

- 🎮 Игроки Steam Deck, которые часто переключаются между режимами
- ⌨️ Пользователи клавиатуры, предпочитающие стандартные схемы управления
- 🎲 Любители удобной навигации в RPG-играх
- 🌍 Игроки, использующие нестандартные раскладки клавиатуры

## 📋 Требования

- **BG3 Script Extender v18+** (автоматически устанавливается через мод-менеджер)
- Baldur's Gate 3 Patch 8+
- Работает в одиночной игре и мультиплеере

## 🚀 Установка

### Через встроенный мод-менеджер BG3 (рекомендуется)
1. Откройте встроенный мод-менеджер в главном меню BG3
2. Найдите "Dialogue Enter Confirm" и подпишитесь
3. Запустите игру - мод активируется автоматически

### Через GitHub Releases
1. Скачайте последний релиз из [Releases](https://github.com/username/bg3-dialogue-enter-confirm/releases)
2. Извлеките `.pak` файл в папку модов BG3
3. Активируйте мод через мод-менеджер

### Через BG3 Mod Manager/Vortex
1. Скачайте `.pak` файл мода
2. Импортируйте в BG3 Mod Manager или Vortex
3. Активируйте мод в порядке загрузки

## 🎯 Использование

1. Войдите в любой диалог в игре
2. Используйте стрелки **↑↓** для навигации между опциями
3. Нажмите **Enter** (или **A** на контроллере) для подтверждения выбора
4. Цифровые клавиши по-прежнему работают как раньше

## 🔧 Устранение неполадок

**Мод не работает:**
- Убедитесь, что BG3 Script Extender установлен и активен
- Проверьте, что мод загружен в правильном порядке
- Перезапустите игру

**Конфликты с другими модами:**
- Большинство UI модов совместимы
- При проблемах отключите другие моды клавиатуры

## 🛠️ Разработка


```bash
git clone https://github.com/username/bg3-dialogue-enter-confirm.git
cd bg3-dialogue-enter-confirm
./build.sh
```

### Технические детали
Мод использует BG3 Script Extender API для:
- Перехвата событий клавиатуры (`Ext.Events.KeyDown`)
- Отслеживания состояния UI диалогов
- Симуляции нажатий цифровых клавиш для существующей системы
