## [1.0.0] - 2024-06-22

### Добавлено
- Первая версия мода Dialogue Enter Confirm
- Поддержка подтверждения диалогов клавишей Enter
- Совместимость с встроенной навигацией стрелками BG3
- Поддержка контроллера (кнопка A)
- Работа в одиночной игре и мультиплеере
- Минимальные требования: BG3 Script Extender v18+
- Совместимость с BG3 Patch 8+

### Технические особенности
- Клиентская реализация для мгновенного отклика
- Перехват событий клавиатуры через BG3SE API
- Отслеживание состояния UI диалогов
- Симуляция нажатий цифровых клавиш
- Поддержка Steam Deck

### Документация
- Полная документация по установке и использованию
- Инструкции для разных методов установки
- Руководство по устранению неполадок

## [0.1.0] - 2024-06-22

- Начальная реализация функционала Enter
