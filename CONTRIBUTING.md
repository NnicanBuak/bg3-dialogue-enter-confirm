## 🔧 Внесение изменений в код

### Подготовка среды разработки

1. **Форкните репозиторий**
2. **Клонируйте ваш форк:**
   ```bash
   git clone https://github.com/ваш-username/bg3-dialogue-enter-confirm.git
   cd bg3-dialogue-enter-confirm
   ```

3. **Создайте ветку для изменений:**
   ```bash
   git checkout -b feature/описание-изменения
   ```

### Требования к коду

- **Lua код** должен следовать стандартным соглашениям
- **Комментарии** на русском языке для сложной логики
- **Тестирование** изменений в игре обязательно
- **Совместимость** с различными конфигурациями модов

### Структура коммитов

Используйте [Conventional Commits](https://www.conventionalcommits.org/):

```
<тип>(<область>): <описание>

<детальное описание изменения>
```

Примеры:
- `feat(input): добавить поддержку кнопки X для отмены`
- `fix(dialogue): исправить обработку множественных диалогов`
- `docs: обновить инструкции по установке`

### Pull Request процесс

1. **Обновите документацию** если нужно
2. **Добавьте изменения в CHANGELOG.md**
3. **Убедитесь, что код работает** в различных сценариях
4. **Создайте Pull Request** с описанием:
   - Что изменено и почему
   - Как тестировались изменения
   - Связанные issues (если есть)

## 📦 Релизы

Релизы создаются автоматически при создании тега:

```bash
git tag v1.0.1
git push origin v1.0.1
```

Версионирование следует [SemVer](https://semver.org/):
- `MAJOR` - несовместимые изменения API
- `MINOR` - новая функциональность (обратно совместимая)
- `PATCH` - исправления ошибок
